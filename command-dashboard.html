Calculation methods & boundaries

All embedded research and building records are retained from the attached tracker. Benefits are cumulative; marginal gains subtract the previous level. Cost invoices are direct next-level costs. Current Alpha 24 and Warrior 23 costs are excluded as already paid; Hospital 20 is included until explicitly started. The route sums every missing level, follows explicit building prerequisites and selects Warrior 24 for the any-one Base 25 training-center gate. Camp 1 levels 25–27 replace Warrior 25–27 as the endpoint. Camp 2/3/4 use the shared Soldier Training Camp client cost table, with instance levels and unlock thresholds kept separate. Unknown outside-route gates block a proposed job rather than being silently satisfied.

Research level zero is meaningful only when explicitly entered. Tree percentages are not converted to unknown individual levels. The prior artifact’s inferred Develop maxima remain estimated. No live tooltip, screenshot or current server mechanics were independently verified. Dataset “verified” describes an internal client match, not live account state.

Local saving depends on browser file-storage support and the file’s location. A visible error appears if storage fails. Export JSON after important changes. Import validates the complete dashboard state before replacing it; the original tracker schema is also supported for research/input migration.
